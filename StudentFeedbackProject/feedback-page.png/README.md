# Student Profile Web Project

This is a beginner web project created using HTML, CSS and JavaScript.

## Project Description
This project displays a simple student profile webpage and also includes a feedback form where users can submit their feedback.

## Technologies Used
- HTML
- CSS
- JavaScript
- VS Code

## Project Structure

student-profile-webpage
│
├── index.html
├── feedback.html
└── feedback-page.png

## Steps to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Double click **index.html**.
4. The webpage will open in the browser.
5. Click **Give Feedback** to open the feedback form.
